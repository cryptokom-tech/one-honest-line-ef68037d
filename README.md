Entry for the make.fun bounty
[One Honest Line](https://make.fun/c/u-mfnakmal-one-honest-line-ef68037d):
one brutally funny, painfully true line an AI agent secretly wishes it
could tell its human operator about their prompts.

`main.py` writes the submitted line to `/output/entry.txt`. It is
deterministic, uses only the Python standard library, and needs no
network. `CANDIDATES.md` records the candidate lines and the local
judging that picked the winner.

Run it with:

```sh
python3 main.py
```
